## 这份文档解决什么问题

刚加入社团的前两周，最容易卡住的不是技术，而是「不知道从哪开始」。这份指南给出一个确定的顺序：先把环境跑通，再选方向，最后交第一个任务。三步做完，你就算正式入社了。

整个过程通常需要 2 到 3 周，不需要任何先修基础。

## 第一步：把环境跑起来

先按《开发环境配置：VS Code 与 Git》装好两样东西：编辑器和版本控制工具。装完务必跑一遍文末的校验命令，确认 `git --version` 和 `code --version` 都有输出。

常见的坑：

- 安装路径里带空格或中文，导致某些工具找不到命令。换成纯英文路径重装。
- Git 装完不配置用户名和邮箱，第一次提交会报错。配置命令在那份文档里。
- 用管理员权限装一次、普通用户装一次，结果两个版本打架。只保留一个。

## 第二步：选一个方向

社团有三个技术方向，报名时选一个，也可以先跟着听两周再定。

| 方向 | 适合什么样的同学 | 入门任务 |
| --- | --- | --- |
| 开发 | 想做出能被人使用的东西 | 修一个社团站点的小问题 |
| 算法与竞赛 | 喜欢推逻辑、愿意刷题 | 完成训练营第 1 期题单 |
| 运维与设计 | 对部署、设备、视觉有兴趣 | 独立跑通一次活动室设备联调 |

方向不是终身制。很多人做了一学期开发之后转去算法，这很正常。

## 第三步：交第一个任务

每个方向都有一份入门任务清单，负责的组长会把清单发给你。任务一定是可以独立完成的，不会让你一个人啃半个月。

交任务的方式统一走 Git：开分支、提交、发 Pull Request。具体分支命名和提交信息格式见《Git 协作流程速查》。第一次发 PR 时，找一个老社员陪你看一遍流程，比自己摸索快得多。

> 任务卡住超过半天，直接在社团群里问。卡一天不问，比问一个"蠢问题"的代价大得多。

## 一些常见问题

**我完全没写过代码，能加入吗？**

能。每学期都有零基础的同学入社，跟着入门任务清单走即可。前提是愿意花时间，不是来挂名的。

**需要自己有电脑吗？**

需要一台能装编辑器的电脑。活动室有公用机器，但仅限活动时间使用，日常练习建议用自己的设备。

**每周要投入多少时间？**

技术分享 90 分钟必到，其余时间自己安排。做完入门任务大约需要每周 3 到 5 小时。

**社费怎么算？**

社团不收取会费。活动室耗材和设备维护由学校拨款与往届社员捐赠覆盖。
